# Блог вебверфь.рф

Статьи для https://вебверфь.рф/blog/. Пишутся в админке [Pages CMS](https://app.pagescms.org),
хранятся в этом репозитории, на сайт попадают сами. Публичный репозиторий сервер забирает без токена;
приватный — с `BLOG_GITHUB_TOKEN` в `/opt/vebverf-bot/.env` (fine-grained, Contents: read, только этот репозиторий).

## Как это работает

```
Pages CMS (браузер) ──коммит──▶ GitHub main ◀──раз в 5 мин── сервер 83.220.175.197
GitHub Actions (06:00 МСК) ─черновик─▶ main        │ build.py → /var/www/verf/blog/
                                                   └ bot.blog_announce → каналы TG и MAX
```

1. **Черновик.** Каждый день в 06:00 МСК (или по кнопке «Написать черновик сейчас» в разделе «Статьи»)
   генератор берёт следующую тему из «Темы для черновиков» и кладёт статью с галочкой «Черновик».
   Правила текста — `prompts/draft.md`, разрешённые факты о нас — `prompts/fakty.md`.
   Если уже лежат 3 непроверенных черновика, генератор по расписанию пропускает день.
2. **Проверка.** Аня открывает черновик, проверяет каждую цифру и ссылку, правит, ставит обложку.
3. **Публикация.** Снять галочку «Черновик» → «Сохранить». Через 5 минут статья на сайте,
   в RSS и sitemap. Дата в будущем — статья выйдет в этот день сама.
4. **Анонс.** Новая статья уходит постом в каналы, заданные на сервере (`BLOG_TG_CHATS`, `BLOG_MAX_CHATS`),
   один раз в каждый канал.

## Для Ани: первый вход

1. https://app.pagescms.org → «Sign in with GitHub» (аккаунт, у которого есть доступ к `andd-maker/vebverf-blog`).
2. Выбрать репозиторий `vebverf-blog`, ветка `main`.
3. Слева: «Статьи», «Темы для черновиков», «Media» (картинки).

## Где что

| Путь | Что |
|---|---|
| `content/posts/*.md` | статьи (Markdown + поля сверху) |
| `content/media/` | картинки → `/blog/media/` на сайте |
| `content/temy.yml` | очередь тем для генератора |
| `.pages.yml` | настройка админки |
| `build.py` | сборщик страниц, только стандартная библиотека Python |
| `deploy/blog_sync.py` | синхронизация на сервере |
| `deploy/install.sh` | установка на сервер (с Mac) |
| `.github/workflows/draft.yml` | генератор черновиков |

## Обслуживание

- Проверить локально: `python3 -m unittest discover -s tests && python3 build.py` → `_site/blog/`.
- Правка `build.py` или `blog_sync.py` на сервер сама не едет (иначе любой коммит исполнял бы код от root):
  `deploy/install.sh` (план) → `deploy/install.sh --go`. Только после «да» Дениса.
- Стоп-краны: блог — `touch /opt/vebverf-blog/STOP`; анонсы — общий `/opt/vebverf-bot/data/MUTE`
  (останавливает и рассылку Сводки).
- Состояние: `cat /opt/vebverf-blog/state.json`, журнал — `journalctl -u vebverf-blog-sync -n 50`.
- Генератору нужен секрет репозитория `CLAUDE_CODE_OAUTH_TOKEN` (`claude setup-token`, подписка Дениса).
- HTML в тексте статьи не выводится, ссылки `javascript:` вырезаются, картинки — только из `/blog/media/`
  (CSP сайта чужие всё равно не пустит).
